# ai-report-tool

JavaとGemini APIを使った、CSV売上分析ツールです。CSVから商品別の売上を集計し、レポートCSVを出力します。さらに、集計結果をGemini APIに送り、日本語の分析文章を生成します。

## 主な機能

- 売上CSVの読み込み
- 商品別売上と全体の合計売上の計算（数量 × 単価）
- 集計結果の画面表示とレポートCSV出力
- AIへの指示文と集計結果のファイル出力
- Gemini APIによる分析文章の生成・保存
- 空行、列数不足、不正な数量・単価の検出と行番号の表示

## 使用技術

| 技術 | 用途 |
|---|---|
| Java 21（JDK） | アプリケーションの実装・実行 |
| Maven | ビルドとライブラリ管理 |
| Jackson Databind 2.18.3 | リクエストJSONの生成・レスポンスJSONの解析 |
| Gemini API | 売上の分析文章生成 |

コードで指定しているモデルは`gemini-3.1-flash-lite`です。HTTP通信にはJava標準の`HttpClient`を使用しています。

## 5クラスの構成

ソースコードは`src/main/java/`にあります。

| クラス | 役割 |
|---|---|
| `Main` | 集計、画面表示、ファイル保存、AI分析を順番に呼び出す |
| `SalesSummary` | 商品別売上と合計売上を保持する |
| `SalesAggregator` | CSVを読み込み、入力チェックと売上集計を行う |
| `ReportWriter` | 集計結果を画面に表示し、`report.csv`と`ai_input.txt`を保存する |
| `GeminiTest` | Gemini APIとの通信、応答のJSON解析、分析結果の保存を行う |

`GeminiTest`は名前にTestが含まれていますが、自動テストではありません。`main()`または`analyze()`を呼ぶと実際にAPIへの通信を行います。

## サンプルデータ

`sample_sales.csv`には、架空のカフェの売上データを10件収録しています。コーヒー、紅茶、りんごジュース、チーズケーキ、クッキーが登場します。

列は次の順序です。

| 列名 | 内容 | 例 |
|---|---|---|
| `date` | 売上日 | `2026-11-01` |
| `product` | 商品名 | `コーヒー` |
| `quantity` | 数量（0以上の整数） | `3` |
| `price` | 単価（円、0以上の整数） | `400` |

```csv
date,product,quantity,price
2026-11-01,コーヒー,3,400
```

見出し行は必須です。プログラムは先頭行を読み飛ばし、2行目以降を集計します。数量と単価はJavaの`int`の範囲内の整数で入力してください。文字コードはUTF-8を使用してください。

## 実行手順

以下はmacOS・Linuxのターミナル（zshまたはbash）での手順です。コマンドはプロジェクト直下、つまり`pom.xml`があるフォルダーで実行してください。

### 1. JavaとMavenを準備する

JDK 21とMavenをインストールし、次のコマンドで確認します。

```sh
java -version
javac -version
mvn -version
```

Javaとjavacが21であり、MavenもJava 21を使用していることを確認してください。Mavenが別のJavaを使用している場合は、`JAVA_HOME`などの環境設定を見直してください。

### 2. APIキーを設定する

Gemini APIを利用できるAPIキーを用意し、実行するターミナルで環境変数`GEMINI_API_KEY`に設定します。次の方法ではキーの入力文字を画面に表示せず、キー自体をコマンド履歴に残しません。

```sh
printf 'Gemini APIキーを入力してください: '
read -r -s GEMINI_API_KEY
printf '\n'
export GEMINI_API_KEY
```

この設定は現在のターミナルで有効です。APIキーはソースコードやREADMEに書かず、GitHubにも公開しないでください。`.env`を作成しても、現在のコードは自動では読み込みません。

### 3. サンプルを入力ファイルとして用意する

プログラムは`sample_sales.csv`ではなく、`sales.csv`を読み込みます。次のコマンドでコピーしてください。

**既存の`sales.csv`がある場合は上書きされるため、必要なデータを先に退避してください。**

```sh
cp sample_sales.csv sales.csv
```

### 4. コンパイルする

```sh
mvn compile
```

初回はMavenがライブラリなどをダウンロードするため、インターネット接続が必要です。このコマンドだけではアプリやGemini API通信は実行されません。`BUILD SUCCESS`はコンパイル成功を示します。

### 5. アプリを実行する

```sh
mvn org.codehaus.mojo:exec-maven-plugin:3.5.0:java -Dexec.mainClass=Main
```

このコマンドは実際にGemini APIへデータを送信します。実行用プラグインは完全な名前とバージョンで指定しているため、`pom.xml`への追加設定は不要です。初回はプラグインのダウンロードも発生します。

画面に商品別売上、合計売上、ファイル保存のメッセージが表示されます。サンプル10件の合計は**11,950円**です。AI分析まで成功すると`analysis.txt`が保存されます。

## 出力ファイル

すべて実行時の作業フォルダーに出力され、既存の同名ファイルは上書きされます。

| ファイル | 内容 |
|---|---|
| `report.csv` | `商品名,売上金額`の見出し、商品別売上、合計の行 |
| `ai_input.txt` | AIへの日本語の指示文、商品別売上、合計売上 |
| `analysis.json` | HTTP 200で返されたAPI応答全体 |
| `analysis.txt` | API応答から取り出した分析文章 |

入力の`sales.csv`、これらの出力ファイル、`target/`、`.env`などは`.gitignore`で除外しています。公開用の`sample_sales.csv`は除外していません。

### エラー時の動作

- CSVに空行、4列未満の行、数量・単価の不正な整数や負の値があると、行番号付きのエラーで集計を中止します。行番号には見出し行も含みます。
- 集計やレポート出力に失敗すると、Gemini APIは呼び出しません。現在のMainはこのエラーを表示して`return`するため、Mavenが`BUILD SUCCESS`を表示する場合があります。画面の「データ処理エラー」も確認してください。
- APIキー未設定、通信失敗、タイムアウト、HTTPエラー、分析文章が見つからない場合は例外で終了します。接続タイムアウトは10秒、リクエストのタイムアウトは120秒です。
- HTTP 400は送信内容、401/403は認証・権限、429は利用枠、500番台はAPI側の問題の可能性を日本語で案内します。
- 失敗しても以前の出力ファイルは自動削除されません。ファイルがあるだけで今回の成功と判断せず、実行結果と更新日時を確認してください。

## 現在の制限事項

- **列順は固定です。** `date,product,quantity,price`の順に用意してください。見出し名の検証や列名による検索は行いません。日付は現在の集計には使いません。
- **簡易CSV形式のみ対応します。** カンマで分割する実装のため、引用符で囲まれたカンマや商品名内の改行などには対応していません。
- 売上は整数・円単位で扱います。小数には対応せず、大きな金額の計算で`int`の範囲を超える場合の検出も行いません。
- **外部AIへのデータ送信が発生します。** 商品別売上、合計売上、指示文がGemini APIに送られます。公開・送信してよいデータだけを使用してください。
- APIの利用にはインターネット接続と利用可能なAPIキーが必要です。実際の利用可否は、指定モデルやAPIの提供状況、利用権限・利用枠に依存します。
